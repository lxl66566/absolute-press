# Configuration (EN)

Site options are passed to `absolutePress(defineSiteConfig({...}))`. Required: `contentDir` (markdown root for the default locale), `title`, `description` and `hostname` (canonical origin used by SEO meta, RSS, sitemap and robots.txt). Optional keys:

| Key                | Type                                                    | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------ | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `locales`          | `Record<string, { lang, label }>`                       | Extra locales; content lives in `<contentDir>/<key>/`, routes get the prefix                                                                                                                                                                                                                                                                                                                                                               |
| `icons`            | `Record<string, string>`                                | Registered SVG icons; frontmatter `icon` must reference a key (build-time check)                                                                                                                                                                                                                                                                                                                                                           |
| `islands`          | `Record<string, string>`                                | Custom islands: PascalCase tag -> module path relative to the project root                                                                                                                                                                                                                                                                                                                                                                 |
| `entryListIslands` | `string[]`                                              | Site island names whose `@@@` children reuse the ExpandableList entry pipeline                                                                                                                                                                                                                                                                                                                                                             |
| `encrypt`          | `{ match, passwords, hint? }[]`                         | Client-side password gates matched against page routes                                                                                                                                                                                                                                                                                                                                                                                     |
| `algolia`          | `{ appId, apiKey, indexName }`                          | Mounts Algolia DocSearch in the navbar                                                                                                                                                                                                                                                                                                                                                                                                     |
| `giscus`           | `{ repo, repoId, category, categoryId }`                | Auto-mounts Giscus comments at the end of article pages                                                                                                                                                                                                                                                                                                                                                                                    |
| `googleAnalytics`  | `string`                                                | GA measurement id, injected at build time                                                                                                                                                                                                                                                                                                                                                                                                  |
| `home`             | `{ feed?, feedPerPage? }`                               | Article feed on locale home pages (`feed` default `true`; docs/landing homes turn it off) and its page size (`feedPerPage`, default `3`)                                                                                                                                                                                                                                                                                                   |
| `archive`          | `{ perPage? }`                                          | Articles per page of one category/tag archive (client-side pagination, default `10`)                                                                                                                                                                                                                                                                                                                                                       |
| `feed`             | `{ rssLimit? }`                                         | Newest articles included in `rss.xml` (default `20`)                                                                                                                                                                                                                                                                                                                                                                                       |
| `seo`              | `{ image? }`                                            | Share-card image for `og:image` (+ `twitter:card: summary_large_image`); public-root path or absolute URL. Unset sites emit `twitter:card: summary` and no `og:image`                                                                                                                                                                                                                                                                      |
| `footer`           | `{ credit? }`                                           | Footer credit line (desktop footer + mobile drawer); default is the CC glyph + framework name; the desktop footer also always shows "Powered by absolute-press" on the right, linked to the framework repo                                                                                                                                                                                                                                 |
| `strictLinks`      | `'off' \| 'warn' \| 'error'`                            | Policy for bare relative markdown links (`guide/a.md`): never rewritten, outside the dead-link check; default `'warn'`                                                                                                                                                                                                                                                                                                                     |
| `related`          | `{ depth?, maxNodes?, maxEdges?, twoHopNodeLimit? }`    | Related-articles graph: BFS depth (default `1`), per-page caps (60 nodes / 240 edges, hub fallback 48)                                                                                                                                                                                                                                                                                                                                     |
| `code`             | `{ lineNumbers?, collapsedLines?, wrap?, copyLabel? }`  | Code block defaults: `true` / `15` / `true`; `collapsedLines: null` disables folding; `copyLabel` overrides the copy button label (default `复制代码`)                                                                                                                                                                                                                                                                                     |
| `readingTime`      | `boolean`                                               | Estimate reading time into the page payload, default `true` (not rendered in the article meta row)                                                                                                                                                                                                                                                                                                                                         |
| `nav`              | `{ exclude?, logo?, tweaks?, order?, align?, social? }` | All navbar options in one place: route prefixes hidden from navbar/sidebar (pages still build); brand image (navbar + mobile drawer, public-root path); display tweaks per top-level directory (`label`/`groups`/`items`); top-level order by directory name; lane alignment (`'center'` splits brand and icon rail, default `'left'`); social icon buttons (`icon` is an `icons` key or a built-in brand, rendered before the RSS button) |
| `lang` / `label`   | `string`                                                | `<html lang>` and switcher label of the default locale (`zh-CN` / `简体中文`)                                                                                                                                                                                                                                                                                                                                                              |

Per-block overrides for code blocks use fence meta (`:wrap=false`, `:collapsed-lines=N`, `{1,3-5}`, `title="..."`); see the [markdown showcase](./markdown.md) and the Chinese [代码高亮](../guide/markdown.md#代码高亮) reference.

The navbar also always renders an RSS button linking `/rss.xml` (base-aware, i18n title `nav.rss`); RSS is always generated and needs no toggle.

`readingTime` estimates from the page body (CJK at 300 chars/min, latin at 200 words/min; frontmatter and code excluded) into `page.readingTime` for payload consumers such as archive cards; the article meta row does not render it. Sitemap content pages carry `<lastmod>` from git; see the [SEO guide](../guide/seo.md).

Multi-locale sites get hreflang alternates automatically: pages mirrored across locale directories (same relative path) cross-link in the head and the sitemap, with `x-default` pointing at the default-locale version; untranslated pages simply opt out. See the [SEO guide](../guide/seo.md).

Pages take exactly five frontmatter keys: `date`, `category`, `tag`, `icon` and `feed`.

Site islands read the page payload through `pagePayload()` from `absolute-press/client` (locale, base, page metadata; re-read per call, kept in sync across soft navigations).

The complete Chinese reference is at [配置参考](../guide/configuration.md); theming is covered in [主题定制](../guide/theme.md).
