# Deep Page

This page sits three levels deep (`guide/advanced/`) and is a live example of multi-level sidebar nesting: the outer "Guide" group nests an "advanced" group, and both levels collapse and expand independently via the arrow at the end of each row. The `advanced/` directory has no index page of its own, so in the navigation it is a plain heading row driven by the arrow; a directory with an index page is clickable as a whole row, and the row label takes the index page's title.

That is all the content — this page exists for its path. See [Getting started](../getting-started.md) for how the directory structure is organized; directories with an index page are clickable as whole rows, and this site's top-level "Guide" is an example.
