# 深层页面

本页位于三级目录（`guide/advanced/`），是侧边栏多层嵌套的现场示例：外层「指南」分组内嵌套「advanced」分组，两层都可以用行尾的箭头独立收起与展开。`advanced/` 目录没有自己的 index 页，所以在导航里它是一行纯标题，靠箭头收放；带索引页的目录则整行可点，行名取 index 页的标题。

内容到这里就结束了——本页存在的意义就是它的路径。目录结构的组织方式见[快速开始](../getting-started.md)；带索引页的目录整行可点，本站的顶层「指南」就是例子。
